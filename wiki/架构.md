# 架构

English: [Architecture](Architecture)

```
┌─────────────────────────────────────────────┐
│ 渲染进程(React 19 + zustand)                │
│  - 7 个页面,无网络、无 Node 能力             │
│  - CSP: connect-src 'none'                  │
└──────────────┬──────────────────────────────┘
               │ contextBridge(白名单 API)
┌──────────────▼──────────────────────────────┐
│ Preload(sandbox: true, contextIsolation)    │
└──────────────┬──────────────────────────────┘
               │ ipcRenderer.invoke(zod 校验)
┌──────────────▼──────────────────────────────┐
│ 主进程(Electron 45)                         │
│  - 协议适配器(chat / anthropic / responses) │
│  - TestRunner(超时/取消/SSE/记录)           │
│  - ConfigStore / SecretStore(用户数据目录)  │
│  - 脱敏 → 历史 → 导出                       │
│  - 诊断规则引擎                             │
│  - 模拟服务子进程管理                        │
└─────────────────────────────────────────────┘
```

## 关键决策

| 决策 | 原因 |
| --- | --- |
| 网络只在主进程 | 渲染进程 CSP 禁止连接;TLS 校验不可关闭 |
| 密钥与配置分离 | `secrets.json`(加密)vs `providers.json`(明文);渲染进程只见末 4 位 |
| 降级必须明示 | safeStorage 不可用 → 仅会话内存 + 界面提示,绝不静默明文 |
| 参数最小化 | 请求体只含用户明确启用的字段(有测试强制) |
| 脱敏在捕获点 | 记录创建瞬间即脱敏;原始密钥只存活一次请求的时长 |
| 原子写入 | 所有 JSON 存储用 tmp+rename |
| Git Data API 快照提交 | 开发网络间歇封锁 github.com;api.github.com 通常可达 |

## 新增协议

实现 `src/main/protocols/types.ts` 的 `ProtocolAdapter` 接口(chat 路径、模型路径、流式事件、非流式解析、目录解析),在 `src/main/index.ts` 的 `CHAT_ADAPTERS` 注册,给 `mock-server/server.mjs` 加故障注入端点,然后补测试。参考 `anthropic-messages.ts` 与 `openai-responses.ts`——每个协议都带 10+ 单元测试与 mock 端到端集成测试。
