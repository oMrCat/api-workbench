# 测试与验证

English: [Testing & Verification](Testing-and-Verification)

## 自动化测试(离线,每次推送)

- **157 项测试**:单元(SSE 解析、URL 拼接、脱敏、诊断规则、存储、导出、各协议适配器、示例工具)+ 集成(经真实 localhost 网络栈对模拟服务跑完整请求闭环)
- **24 个 UI 场景**(`npm run uitest`):DOM 驱动 + 截图目检——表单、流式、取消按钮、诊断面板、对比、性能、最小窗口布局、无内嵌 webview

## 每次推送的 CI

| Job | 内容 |
| --- | --- |
| 测试(ubuntu + windows) | 类型检查 + 全部测试,双系统真实运行 |
| macOS 打包 | 产 dmg → **运行打包产物 `.app --smoke`(9 步)** |
| Windows 打包 | 产 NSIS + win-unpacked → **运行打包产物 `.exe --smoke`(9 步)** |

冒烟步骤:窗口加载 → React 挂载 → CSP → 密钥存储模式 → 配置闭环 → 模拟服务子进程 → 非流式闭环(断言脱敏)→ 流式闭环 → 401 + 诊断 → 干净退出。

## 已验证 vs 未验证(如实清单)

**已验证**:上面全部——自动化测试、干净 Windows/macOS 机器上的打包产物冒烟、macOS 本机安装测试。

**未验证**(需要所有者):
- 真实服务商 API 调用(三种协议均按官方文档实现;模拟服务按真实行为设计)
- Windows 安装器双击体验(Smartscreen 提示、快捷方式)——exe 本体每次推送都被冒烟实测
- macOS 签名/公证(无开发者证书)

## 需求书的 18 个场景

原始需求要求 18 个测试场景(正常/流式/UTF-8 跨块/401/403/404/429/5xx/超时/取消/非 JSON/空目录/畸形目录/网络中断/脱敏/URL 拼接/配置持久化/安全存储降级)。每个都有具名测试——对照表见仓库内 `docs/testing.md`。
